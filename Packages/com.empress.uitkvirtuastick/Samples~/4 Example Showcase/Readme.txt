Demo 4: Example Showcase

This demo presents four VirtuaStick variations, each tailored for a different control style:

- VirtuaStickDpad: Combines a basic stick with a visual D-Pad overlay.
- VirtuaStickPuzzleDpad: Restricts movement to 2D axis only (no diagonals), with a simplified D-Pad style (no visible handle).
- VirtuaStick2DPlatformer: Allows only horizontal movement and shows two arrows (left/right), ideal for 2D side-scrollers.
- VirtuaStickRacingPad: A circular pad that mimics a steering wheel, rotating based on stick direction. The handle is hidden and internal.

All variations are implemented as separate scripts that inherit from VirtuaStick. You can find them in the same folder as the scene for easy reference and customization.

Use this demo to learn how to extend VirtuaStick to match different gameplay needs without altering its core behavior.
