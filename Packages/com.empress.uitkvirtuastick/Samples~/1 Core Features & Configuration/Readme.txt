Demo 1: Core Features & Configuration

This demo showcases the core features of VirtuaStick and allows full runtime configuration.
On the right panel, you can interact with various UI controls to adjust:

Stick radius and movement range

Axis restriction modes (Free, Horizontal, Vertical)

Dynamic vs. Fixed position

Visual feedback options like borders and direction lines

Use this demo to understand how VirtuaStick can adapt to different gameplay scenarios and UI setups. Every parameter is fully exposed at runtime, allowing live testing and instant feedback.
